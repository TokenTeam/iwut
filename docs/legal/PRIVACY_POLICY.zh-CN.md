# 掌上吾理隐私政策

更新日期：2026 年 10 月 19 日

生效日期：2026 年 6 月 8 日

TokenTeam（以下简称“我们”）运营“掌上吾理”。本政策适用于本应用及我们提供的配套网站、配置、更新和下载服务，说明个人信息的处理方式及您的权利。

掌上吾理是一款校园工具，提供课表管理、考试安排与成绩查询、校园网辅助登录等功能。请在使用相关功能前阅读本政策，特别是第三方服务和跨境处理说明。**保存的账号凭据、课表、考试安排和成绩查询结果主要存储在设备本地；诊断、性能观测、配置和下载服务会处理必要的设备、运行及网络信息，部分信息涉及境外处理。**本应用不提供广告投放、商业营销或基于个人特征的定向推送。

## 一、个人信息的收集与使用

我们按照实现功能所必要的范围处理信息。除依法可以不经同意的情形外，涉及个人信息的处理以您的同意为基础；依法需要单独同意的，另行征求。系统权限授权与个人信息处理同意是不同事项。

### 1. 学校账号与校园服务

您绑定学校账号时，本应用处理学号或账号、密码，以及学校系统返回的姓名、一卡通号和学院等信息，用于身份验证、自动登录和校园服务访问。密码使用系统安全存储能力保存，其他绑定信息保存在本地。登录请求及必要凭据会提交至学校统一身份认证或相关学校系统；WebView 访问还会产生 Cookie、缓存和会话数据。

学校登录要求短信验证时，本应用会处理学校页面返回的手机号尾号及您输入的验证码，用于展示验证提示并向学校认证页面提交验证码。

您使用校园网辅助登录时，本应用处理校园网账号、密码、当前 Wi-Fi 或网络状态及网关返回结果，用于完成认证和判断连接状态。凭据保存在系统安全存储或原生安全凭据区域，认证时提交至校园网网关。

### 2. 课表、考试安排与成绩查询

本应用在您使用相应功能时处理以下信息：

- 课表管理：导入的本科生、研究生、实验课程，或您手动添加的课程，包括课程名称、教师、教室、周次、星期、节次或自定义时间、备注、实验课座位、课程来源及学期开始日期，用于展示和编辑课表；
- 考试安排：课程名称与代码、考试时间、地点、座位、教师、考试状态、说明、未安排考试的课程及导入时间，用于展示考试安排、倒计时和生成本地提醒；
- 成绩查询：学期、课程名称与代码、课程性质、成绩、学分、重修信息及导入时间，用于按学期展示从学校查询并导入的成绩。

导入时，本应用访问学校教务、研究生或实验教学等相应系统，导入结果保存在设备本地。手动添加和编辑的课程也保存在本地。

开启日历同步后，本应用经授权将课程信息写入系统日历；开启课程或考试提醒后，相应名称、时间、地点等信息会用于本地通知。桌面小组件使用本地课表数据展示课程，iOS 实时活动使用即将开始的课程名称、教室和上课时间展示课前倒计时；上课自动免打扰根据本地课表和设置调度系统规则。上述功能的可用范围取决于系统和应用版本。

### 3. 内嵌校园服务页面

本应用通过内嵌网页提供空闲教室、图书馆、校园卡及校园资讯等服务入口。您打开相关页面时，页面及其连接的服务会处理相应查询请求和网络信息；需要学校认证的，登录信息会提交至学校系统。

对于我们提供的校园服务页面，本应用还可向页面提供已绑定的姓名、学号、一卡通号、学院等基本信息，并在设备上执行相应的学校系统查询，将结果交给页面展示。相关页面设置和缓存可存储在本地。具体处理取决于您访问的服务和执行的操作。

### 4. 个性化、扫码与分享

主题、语言、课表配色、背景图片及提醒等设置保存在本地。选择课表背景时，本应用读取您主动选中的图片。

扫一扫用于识别二维码；对本应用支持的单门课程和课表配色分享码，会展示预览，并在您确认后将相应课程或配色导入本地。生成分享码时，会将您选择的课程内容或配色编码为分享内容。您主动复制、导出或分享时，相应文本、二维码或文件会交给系统剪贴板、分享面板或您选择的接收方。

### 5. 公告、配置与更新

本应用在启动、返回前台或您手动检查时获取公告、远程配置和版本信息，并通过 Expo Updates 检查、下载兼容的热更新。安装包下载在您选择相应下载入口后进行。

更新请求可能携带应用版本、系统平台、运行时版本、更新通道、更新标识、项目标识及随机生成的安装实例标识。获取公告、配置、更新或安装包时，相关服务器及内容分发网络（CDN）还会接收 IP 地址、请求时间、资源路径、请求头和响应状态等网络信息，用于交付内容、判断兼容性和保障服务安全。

### 6. 错误诊断、性能观测与反馈

在非开发模式下，本应用启用 Sentry 错误诊断及 Expo Observe 性能观测，可能在启动、运行、异常发生或后续发送待上报事件时向相应服务发送信息：

- 错误诊断：异常信息、错误堆栈、崩溃记录、模块标签、应用及构建版本、设备型号、系统版本，以及错误发生前的操作、控制台输出和网络请求等运行上下文；
- 性能观测：启动和页面交互耗时、页面路由、更新加载情况、运行状态、设备和系统信息、安装实例标识，以及未处理的 JavaScript 异常信息。随机生成的安装实例标识用于关联同一安装实例的记录，不属于完全匿名的信息；
- 用户反馈：您主动提交的反馈内容，以及您选择填写的邮箱，用于定位问题和回复。

这些信息用于定位故障、评估性能和改善稳定性。学校账号密码、课表、考试安排和成绩查询结果不是诊断上报所需的信息，但异常信息和运行上下文可能包含相关功能运行时的内容。请勿在反馈中填写密码、验证码等不必要的信息。

### 7. 本地日志

本应用在设备上滚动保存运行日志，包括控制台输出、错误信息及排查所需的应用和设备信息。您主动导出并选择接收方时，导出的文件会交给相应接收方。部分错误或控制台内容也可能随前述诊断事件自动上报。

## 二、系统权限与敏感信息

本应用根据功能和操作系统要求使用以下权限或系统能力，您可以在系统设置中管理可撤销的授权：

| 权限或系统能力         | 用途                                                   |
| ---------------------- | ------------------------------------------------------ |
| 网络访问               | 学校系统访问、校园网认证、公告配置、更新下载和诊断上报 |
| 日历                   | 创建、更新或删除本应用生成的课程日历                   |
| 通知、闹钟和提醒       | 课程与考试提醒、后台调度及免打扰规则切换               |
| 免打扰访问             | 根据本地课表启停本应用创建的免打扰规则                 |
| 相机                   | 扫描二维码                                             |
| 位置或 Wi-Fi 相关权限  | 在部分系统上读取 Wi-Fi 信息以辅助校园网认证            |
| 图片选择、相册或媒体库 | 读取您选择的背景图片，具体授权方式取决于系统           |
| 剪贴板、文件和分享     | 执行您主动发起的复制、导出或分享                       |
| 小组件和实时活动       | 在桌面展示课表，在支持的系统上展示课前倒计时           |

并非上述每项能力都会触发系统权限弹窗。拒绝或撤销授权可能影响对应功能。

**请妥善保管账号凭据、设备与备份。**凭据泄露可能导致账号被冒用，身份信息、课表、考试安排、成绩或网络信息泄露可能影响个人隐私。涉及敏感个人信息时，我们仅在具有特定目的、充分必要并采取严格保护措施的前提下处理，并依法履行单独告知、单独同意等义务。

## 三、存储期限与安全保护

1. 保存的学校账号密码使用 Expo SecureStore 存储，校园网凭据使用原生安全凭据模块保存。绑定信息、课表、考试安排、成绩查询结果和设置等主要保存在本地，保存至对应数据被删除、替换或应用数据被清除。解绑账号不等于删除已经导入的所有数据，清理缓存也不等于清除全部应用数据。
2. 本地日志按文件大小和数量滚动清理。学校网页的 Cookie 和缓存会在解绑、导入结束或相关清理操作中按功能实现清理，具体范围受 WebView 和系统能力限制。
3. 服务器上的诊断、反馈和网络日志仅在实现相应目的所必要的期限内保存，期限受实际服务配置、所用产品和依法适用的保存义务影响。您可以联系我们查询适用于相关记录的期限或申请删除；第三方的处理规则见第四节。
4. 卸载应用通常会移除应用沙盒内数据，但系统安全存储、系统日历、小组件、备份及已分享文件可能仍有保留，需要通过相应系统或接收方进一步清理。
5. 我们采取系统安全存储、传输保护和必要的访问限制等措施保护信息。部分学校系统或校园网认证接口可能使用 HTTP，凭据传输的保护程度受相应接口限制。发生个人信息安全事件时，我们将依法采取补救措施并履行通知、报告等义务。

## 四、第三方服务及信息提供

我们不会出售您的个人信息。为实现相关功能，本应用使用以下第三方服务。委托处理个人信息时，我们依法约定处理目的、范围和安全责任，并进行监督；向其他个人信息处理者提供信息时，依法履行告知、取得同意等义务。

### 1. Sentry

提供方为 Functional Software, Inc.（Sentry）。本应用通过 Sentry React Native SDK 提供错误诊断及反馈服务，处理第一节所述的错误、设备、运行上下文、反馈内容及可选邮箱，以及 IP 地址等通信信息。当前接收服务位于美国区域。

隐私政策及联系渠道：[Sentry 隐私政策](https://sentry.io/privacy/)。

### 2. Expo

提供方为 650 Industries, Inc.（Expo）。Expo Observe 用于性能观测，处理第一节所述性能、设备、安装实例标识和相关错误信息，可能在中国大陆以外地区处理信息。Expo Updates 用于更新检查和资源下载，处理更新兼容性、安装实例标识等信息；本应用使用自定义更新地址，相关请求及资源由我们和托管方处理。

隐私政策及联系渠道：[Expo 隐私政策](https://expo.dev/privacy)、[Expo 联系页面](https://expo.dev/contact)。

### 3. Cloudflare 与内容分发服务

Cloudflare, Inc. 为部分配置下发、资源及安装包下载提供网络、托管或内容分发支持，处理 IP 地址、请求时间、资源路径、请求头、响应状态及安全防护所需的网络信息。请求可能经过中国大陆以外的节点，相关信息可能在境外处理或存储。公告、配置和更新信息还通过本应用使用的 CDN 或镜像分发渠道提供。

隐私政策及联系渠道：[Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

### 4. 学校系统与用户选择的接收方

学校统一身份认证、教务、研究生、信息门户、教学及校园网系统，由相应学校部门或服务方运营。您使用有关功能时，必要的认证和查询信息会发送至相应系统。您打开外部页面或向他人分享内容时，接收方按其适用规则处理信息。

除上述情形及您另行授权外，我们仅在法律法规允许的范围内提供或公开个人信息。因合并、分立、解散等原因转移个人信息时，我们将依法告知接收方信息，并要求其继续履行保护义务；接收方变更处理目的或方式的，依法重新取得同意。第三方隐私政策不免除我们对本应用个人信息处理的责任。

## 五、个人信息的跨境处理

**本应用的境外处理主要涉及第四节所列 Sentry、Expo 云服务及 Cloudflare 服务，处理的信息、目的及接收方见第一、四节。**学校登录、课程或成绩查询请求发送至相应学校系统。

涉及个人信息出境时，我们将依法履行告知、取得单独同意、个人信息保护影响评估及适用的出境程序，采取必要措施保护信息安全。**同意本政策或用户协议，不替代依法需要另行取得的单独同意。**

您可以通过第九节的联系方式查询跨境处理情况，或按第六节行使相关权利，我们将在必要核验后处理或协调境外接收方处理。也可以通过第四节所列渠道向接收方提出请求。

## 六、您的权利与选择

您有权依法知情、决定、限制或拒绝个人信息处理，查阅、复制、更正、补充和删除个人信息，以及撤回同意、要求解释处理规则。

您可以在应用内解绑学校账号、清除校园网凭据、编辑或删除课程、重新导入考试安排或成绩，以及调整相关设置；需要清除全部本地应用数据时，可使用系统提供的应用数据管理或卸载功能，注意第三节所述的系统数据保留情况。您也可以在系统设置中撤销相关权限。

对于我们或受托服务保存的信息，以及撤回相应同意的请求，可通过第九节联系我们；目前应用内未提供独立的诊断上报开关。撤回同意不影响撤回前基于同意进行的处理活动的效力；拒绝非必要的信息处理不应影响基本功能的使用。

我们将在必要核验身份后依法及时处理请求；不能满足请求的，将说明理由。学校系统保存的源数据需向学校管理方申请处理，已主动分享给第三方的数据可联系接收方处理，我们将在职责范围内提供协助。

## 七、未成年人保护

本应用主要面向高校用户。未成年人应在监护人指导下阅读本政策并使用服务；处理不满十四周岁未成年人个人信息，应取得监护人同意并适用专门保护规则。如发现未经所需同意收集的相关信息，我们将依法核实、删除或采取其他保护措施。监护人可通过第九节联系我们。

## 八、政策更新

我们会根据功能及处理活动变化更新本政策，并通过应用内页面或其他适当方式告知。处理目的、方式、信息种类或接收方等发生重大变化时，我们会作出显著提示，并依法重新征求同意；更新本政策本身不构成对新增处理活动的授权。
